# UI and UX Requirements

## Design direction

Build premium, modern enterprise software with restrained glass surfaces,
readable typography, clear hierarchy, data-dense but legible tables, polished
charts, consistent icons, and appropriate motion. When provided, Google Stitch
designs are the primary visual reference.

## Navigation and responsive design

Use a collapsible left sidebar rather than conventional top navigation. Support
expanded, minimized icon, and mobile drawer modes; active states; and
role-aware navigation.

Layouts must adapt to desktop, tablet, and mobile without hiding important
workflow actions. POS favors speed; finance and inventory favor clarity.

## Accessibility and feedback

Provide loading, empty, and error states; confirmation dialogs; success feedback;
accessible forms; responsive tables; and keyboard navigation. Use semantic
controls, visible focus, adequate contrast, and labels for icon-only actions.

## POS interaction requirements

Prioritize barcode scanning and keyboard workflows. Keep product lookup,
categories, cart, quantity edits, customer, payment options, totals, and checkout
available without unnecessary navigation or modal interruptions.
