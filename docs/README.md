# Quick Business Platform

Quick is a modern multi-tenant business management platform for retail,
supermarket, wholesale, distribution, and multi-branch operations.

## Included Foundation

- Premium responsive dashboard
- Revenue, expense, profit, category, transaction, and stock views
- Fast POS workspace with search, categories, cart, quantities, customer selection,
  tax calculation, configurable payment buttons, and checkout summary
- Responsive sidebar and mobile navigation
- Strict TypeScript Next.js App Router structure
- Cloudflare D1 migration and seed-ready project configuration
- Architecture and implementation documentation

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
